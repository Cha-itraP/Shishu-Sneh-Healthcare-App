🍼 Shishu-Sneh — Baby Healthcare Companion

An AI-powered Android app to support new mothers in tracking a baby’s first-year health, growth, and development.

📖 Overview

Shishu-Sneh is a healthcare-focused Android application designed to bridge the information gap faced by new mothers—especially in rural areas.
It acts as a digital companion, helping track baby growth, ensure timely vaccinations, and provide personalized feeding guidance using simple, accessible design.

✨ Key Highlights

📊 Real-time Growth Monitoring
⏰ Automated Vaccination Reminders
🧠 AI-assisted Guidance & Insights
🥗 Personalized Feeding Recommendations
✅ Interactive Milestone Tracking
🌍 Designed for Accessibility & Simplicity

🚀 Features:

📈 Growth Tracking
Track baby’s weight & height
Visual progress using charts (MPAndroidChart)
Monthly trend analysis

💉 Vaccination Management
Smart reminders based on DOB
Displays disease prevention info
Ensures no missed immunizations

🥗 Feeding Guidance
Daily nutrition tips for:
Infant
Mother
Easy-to-understand recommendations

✅ Development Milestones
Track key growth indicators
Example: “Can the baby hold their head up?”
Simple Yes/No tracking system

🔔 Smart Notifications
Automated alerts using WorkManager
Timely reminders without manual tracking
